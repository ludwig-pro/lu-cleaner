## Your stack moves fast. So should your cleanup.

AI coding agents changed what fills a developer's disk. Every Codex, Cursor, Conductor or Claude Code task can spawn a **git worktree** with its own `node_modules`, `ios/Pods` and Android build. Simulators silently collect gigabytes of UI-test recordings. Package managers keep several global caches and node versions. General-purpose cleaners either don't know these places, or deliberately stay away from them.

lu-cleaner knows them — and knows which ones are safe to remove.

<CardGrid>
	<Card title="AI agent worktrees" icon="seti:git">
		Finds every linked worktree (Codex, Cursor, Conductor, Claude Code, manual), shows its branch and status — clean, dirty, unpushed, merged, orphaned — and removes finished ones with `git worktree remove`. Branches are always kept.
	</Card>
	<Card title="React Native aware" icon="seti:react">
		npkill-style scan of `node_modules`, `ios/Pods`, `ios/build`, `android/app/build`, `.gradle`, `.cxx`, `.expo`… with marker files and git-ignore checks so a folder named `build` that is source code is never touched.
	</Card>
	<Card title="Simulators & emulators" icon="laptop">
		iOS simulators, runtimes, orphan device folders, XCTest recordings and unified logs; Android AVDs, unused system images, NDKs and Gradle distributions — including SDKs on external drives.
	</Card>
	<Card title="Safe by design" icon="approve-check">
		Every path is re-checked right before deletion: protected credentials and configs, inode identity, running apps, open databases, processes working inside, uncommitted work. Dry-run everywhere.
	</Card>
	<Card title="Fast" icon="rocket">
		Written in Go, with native macOS reads and results streamed as they arrive. The default `eco` mode limits load; use `--scan-mode fast` when your Mac has room to accelerate.
	</Card>
	<Card title="Scriptable & LLM-friendly" icon="document">
		`--json` everywhere, strict rules for non-interactive `--yes`, and this documentation is available as [llms.txt](/lu-cleaner/llms.txt) for your coding assistant.
	</Card>
</CardGrid>

## Take the wheel.

<Tabs>
	<TabItem label="Interactive">
		```bash
		go install github.com/ludwig-pro/lu-cleaner/cmd/lu-cleaner@latest
		lu-cleaner            # dashboard: you pick what to remove, nothing is preselected
		lu-cleaner clean --smart   # same, but starts with the recommended items selected
		```
	</TabItem>
	<TabItem label="One category">
		```bash
		lu-cleaner clean              # the picker again, nothing preselected
		lu-cleaner worktrees          # only git worktrees
		lu-cleaner artifacts          # only node_modules, Pods, builds…
		```
	</TabItem>
	<TabItem label="Scripted">
		```bash
		lu-cleaner scan --json > report.json
		lu-cleaner clean --yes --smart --dry-run   # the plan, nothing deleted
		lu-cleaner clean --yes --smart             # clean the recommended items
		```
